    Сообщение

    📘 Справка · ВОЛС Телеком

    Что это

    Браузерное приложение для проектирующих волоконно-оптические линии связи. Позволяет за один выезд собрать полевые данные, построить трассу, рассчитать материалы и сформировать исполнительную документацию.

    Кому поможет

    Руководителям проектов, ТУ (Территориальным управляющим), СИ (сервисным инженерам), ДАБ (дежурно-аварийной бригаде), монтажникам, полевым инженерам.

    Для каких задач

    • До строительства: составление схемы для запроса ЛТР, определение маршрутов строительства с координатами опор
    • Во время строительства: отчёты о ходе работ, корректировка трассы
    • После строительства: предоставление исполнительной схемы строительства с фактическими координатами

    Почему удобно

    • Один файл (html) — работает из браузера, без установки и бэкенда
    • Офлайн совместим — html страница может храниться локально на ПК, интернет требуется только для подложек карт
    • Автосейв — данные не теряются при закрытии вкладки
    • Фото → точки — JPG с GPS автоматически становятся точками на карте
    • Сразу документы — схема А4, ёмкость, расчёт материалов и ведомость генерируются автоматически

    Быстрый старт

    1. Откройте файл html в браузере
    2. Нажмите 📍 Точка (или N) — включится режим добавления точек
    3. Кликайте по карте или загружайте JPG с GPS через drag-and-drop
    4. Настраивайте ёмкость кабеля и параметры запаса в разделе ⚙️
    5. Откройте 📐 Схема и 📋 Ведомость для просмотра результатов
    6. Экспортируйте через кнопки в футере (KML, TXT, PNG, CSV)

    Функционал

    Импорт данных: JPG с EXIF/GPS → автоматическое создание точек, KML/KMZ (Google Earth), TXT с координатами (формат: lat,lng), ручное добавление кликом по карте.

    Редактирование: перетаскивание точек (drag-and-drop в списке и на карте), массовое выделение: Ctrl+клик / Shift+клик, шаблоны опор: СВ-95, ЖБ, металлические, массовое редактирование участков кабеля (ёмкость, стиль, цвет), Undo/Redo (Ctrl+Z / Ctrl+Y).

    Расчёты

    • Физическая длина трассы по формуле Хаверсина
    • Запас на провисание (%) и разварку (м)
    • Статистика по типам кабеля (1/4/8/16/24/32/48/64/72/96 волокон)
    • Калькулятор арматуры (УКН, ODWAC, бирки, лента, скрепы)

    ️ Важно: расчёты арматуры и статистика кабелей пока работают только для плоского кабеля (1, 4, 8, 16 волокон). Для кабелей другой конструкции расчёты не производятся.

    Визуализация

    • 11 подложек: OSM, Google, Яндекс, ESRI, OpenTopoMap, CartoDB Dark
    • Раздельные фильтры отображения для карты и схемы
    • Схема А4 с змейкой (до 8 точек в ряду)
    • Строительная ведомость с накопительным метражом

    Экспорт

    • KML (Google Earth)
    • TXT с координатами
    • PNG (исполнительная документация: карта + сводка + схема)
    • CSV ведомость (с BOM для Excel)
    • Скриншот интерфейса
