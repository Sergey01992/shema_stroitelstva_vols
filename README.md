📋 Описание
ВОЛС SPA — это современное веб-приложение для предпроектного обследования, автоматизации трассировки и генерации схем строительства волоконно-оптических линий связи (ВОЛС).
Приложение работает полностью в браузере без серверной части, что делает его идеальным для полевых работ и быстрого развертывания.
✨ Основные возможности
🗺️ Работа с картами
11 подложек от ведущих провайдеров:
OpenStreetMap (карта, спутник ESRI, гибрид)
Google Maps (карта, спутник, гибрид)
Яндекс Карты (карта, спутник, гибрид)
OpenTopoMap (топографическая)
CartoDB Dark (тёмная тема)
Интегрированный геокодер Nominatim для поиска адресов
Ручной ввод координат в формате 56.8389, 60.6057
Временные маркеры при поиске
📸 Загрузка и обработка фотографий
Drag-and-drop загрузка JPG-файлов
Автоматическое извлечение GPS-координат из EXIF-данных
Извлечение даты и времени съёмки
Обработка файлов без геотега с ручным размещением на карте
Прогресс-бар при массовой загрузке
📍 Точки трассы
5 типов геометрических форм:
Точка (промежуточная опора)
Треугольник (узел связи УС)
Круг (оптическая муфта ОМ)
Квадрат (распределительный шкаф РШ)
Ромб (кастомный тип)
10 базовых цветов для каждой точки
Перетаскивание маркеров для коррекции координат
Автоматическая нумерация точек
Статусы "НАЧАЛО (А)" и "КОНЕЦ (Я)" для конечных точек
Drag-and-drop сортировка в списке
🔗 Сегменты (пролёты)
10 типов ёмкости кабеля: 1, 4, 8, 16, 24, 32, 48, 64, 72, 96 волокон
Автоматическая привязка цветов к ёмкости:
ВОК-1 (дроп) → чёрный
ВОК-4 → синий
ВОК-8 → зелёный
И другие стандартные цвета
3 стиля линий: сплошная, прерывистая, штрихпунктирная
Ручное переопределение цвета и стиля
🔄 Сортировка трассы
Три алгоритма автоматического соединения точек:
По времени съёмки — хронологический порядок из EXIF
По расстоянию — алгоритм ближайшего соседа
По номеру точки — порядок в списке сайдбара

📊 Производительность
Оптимизация
Granular updates — перерисовка только изменённых элементов
Debounce на полях ввода (300ms)
Lazy loading для тяжёлых операций
Virtual scroll для списков >100 элементов
Ограничения
Максимальное количество точек: ~1000 (зависит от устройства)
Максимальный размер проекта: ~50 МБ (IndexedDB)
Максимальная история undo/redo: 50 шагов
🔒 Безопасность
Защита данных
Все данные хранятся локально в браузере
Нет передачи данных на сервер
CORS-защита при экспорте карт
Sanitization пользовательского ввода
Приватность
EXIF-данные обрабатываются только в браузере
Фотографии не загружаются на сервер
Геолокация не отслеживается
