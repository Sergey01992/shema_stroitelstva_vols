## 📋 Описание

**ВОЛС SPA** — современное веб-приложение для предпроектного обследования, автоматизации трассировки и генерации схем строительства волоконно-оптических линий связи.

Приложение работает полностью в браузере без серверной части (Single Page Application), что делает его идеальным для полевых работ и быстрого развёртывания на GitHub Pages.

## ✨ Основные возможности

### 🗺️ Работа с картами

- **11 подложек** от ведущих провайдеров:
  - OpenStreetMap (карта, спутник ESRI, гибрид)
  - Google Maps (карта, спутник, гибрид)
  - Яндекс Карты (карта, спутник, гибрид)
  - OpenTopoMap (топографическая)
  - CartoDB Dark (тёмная тема)
- Интегрированный геокодер Nominatim для поиска адресов
- Ручной ввод координат в формате `56.8389, 60.6057`
- Временные маркеры при поиске

### 📸 Загрузка и обработка фотографий

- Drag-and-drop загрузка JPG-файлов
- Автоматическое извлечение GPS-координат из EXIF-данных
- Извлечение даты и времени съёмки
- Обработка файлов без геотега с ручным размещением на карте
- Прогресс-бар при массовой загрузке

### 📍 Точки трассы

- **5 типов геометрических форм**:
  - Точка (промежуточная опора)
  - Треугольник (узел связи УС)
  - Круг (оптическая муфта ОМ)
  - Квадрат (распределительный шкаф РШ)
  - Ромб (кастомный тип)
- 10 базовых цветов для каждой точки
- Перетаскивание маркеров для коррекции координат
- Автоматическая нумерация точек
- Статусы «НАЧАЛО (А)» и «КОНЕЦ (Я)» для конечных точек
- Drag-and-drop сортировка в списке

### 🔗 Сегменты (пролёты)

- **10 типов ёмкости кабеля**: 1, 4, 8, 16, 24, 32, 48, 64, 72, 96 волокон
- Автоматическая привязка цветов к ёмкости:
  - ВОК-1 (дроп) → чёрный
  - ВОК-4 → синий
  - ВОК-8 → зелёный
  - И другие стандартные цвета
- 3 стиля линий: сплошная, прерывистая, штрихпунктирная
- Ручное переопределение цвета и стиля

### 🔄 Сортировка трассы

Три алгоритма автоматического соединения точек:

1. **По времени съёмки** — хронологический порядок из EXIF
2. **По расстоянию** — алгоритм ближайшего соседа
3. **По номеру точки** — порядок в списке сайдбара

### 🎨 Фильтры отображения

- Отображение названий фото
- Отображение заметок
- Отображение геометки (координат)
- Отображение ёмкости кабеля
- Отображение длины пролётов
- Отображение сводки параметров
- Режим «УО чёрным, текст красным»
- Цветная подложка под текст на схеме
- **Переключатель «Только схема»** для каждого фильтра

### 📐 Схема трассы А4

- Автоматическая генерация схемы в альбомной ориентации
- Динамическая высота с авто-змейкой при >8 точках в ряду
- S-образные переходы между рядами
- Автоматический перенос длинных подписей
- Отображение особых отметок красным цветом
- Синхронизация с картой в реальном времени

### 📊 Строительная ведомость

Таблица с детализацией каждого пролёта:

| № | Нач. точка | Геометка нач. | ВОК нач., м | Кон. точка | Геометка кон. | ВОК кон., м | Ёмк. | Длина, м |
|---|-----------|--------------|-------------|-----------|--------------|-------------|------|----------|
| 1 | Опора 1 | 56.786, 60.486 | 0.0 | Опора 2 | 56.786, 60.486 | 15.0 | 4 | 15.0 |
| 2 | Опора 2 | 56.786, 60.486 | 15.0 | Опора 3 | 56.785, 60.486 | 67.1 | 4 | 52.1 |

- Экспорт в CSV с кодировкой UTF-8 + BOM

### 🧮 Калькулятор арматуры

Автоматический расчёт материалов для плоского кабеля (1/4/8 волокон):

- УКН-мини (узлы крепления натяжные)
- Анкерные зажимы ODWAC-22
- Бирки маркировочные ВОЛС
- Лента монтажная стальная
- Скрепы/скобы для ленты

### 💾 Управление проектом

- Сохранение проекта в JSON
- Загрузка проекта из файла
- Автосохранение каждые 10 секунд (IndexedDB + localStorage)
- Восстановление автосейва
- История действий с undo/redo (до 50 шагов)

### 📤 Экспорт данных

- **Исполнительная документация PNG** — сборка карты, сводки и схемы
- **Скриншот окна** — моментальный снимок через html2canvas
- **KML экспорт** — для Google Earth и ГИС-систем
- **KML импорт** — загрузка существующих трасс
- **CSV ведомость** — для Excel и Google Sheets

## 🛠️ Технологии

### Frontend
- **HTML5** — семантическая разметка
- **CSS3** — CSS Variables, Flexbox, Grid, анимации
- **JavaScript (ES6+)** — модульная архитектура IIFE

### Библиотеки
- **Leaflet.js 1.9.4** — интерактивные карты
- **Leaflet Control Geocoder** — геокодирование Nominatim
- **EXIF.js 2.3.0** — извлечение метаданных из фото
- **html2canvas 1.4.1** — рендеринг скриншотов

### Хранение данных
- **IndexedDB** — основное хранилище проектов
- **localStorage** — резервное копирование

### Архитектура
- **Event Bus** — развязка компонентов
- **Command Pattern** — undo/redo система
- **Single Page Application** — один файл index.html
- **No-Backend** — полностью клиентское приложение

## 🚀 Установка и запуск

### Вариант 1: Локальный запуск
1. Скачайте файл `index.html`
2. Откройте его в любом современном браузере
3. Готово! Приложение работает без установки

### Вариант 2: GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите файл `index.html` в корень репозитория
3. Включите GitHub Pages в настройках репозитория
4. Приложение доступно по адресу `https://username.github.io/repo-name`

### Вариант 3: Локальный сервер
```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
